# Delivery session counts

For a representative clean R0/R1 delivery, the previous sequence launched five sessions: issue risk assessment, implementer, draft diff risk assessment, reviewer, and approval-only reviewer. The new sequence launches three: implementer, independent draft diff risk assessor, and independent reviewer who approves the green exact head in the same session. Drive readies and enables eligible auto-merge mechanically. Fix rounds, changed heads, CI failures and owner holds can add work; configured host and model assignments remain in force. An owner-set risk label remains a floor; without an issue assessment the initial model uses R1 or the higher floor.

These are launch counts, not measured token or cost savings. Token usage depends on context, models, retries and host billing; no usage or price data was collected.
