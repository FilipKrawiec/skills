# Task-Packet Verification Example

This static version-2 packet demonstrates the metadata gate for a completed, non-Git isolated-copy slice. Its `evidence` records the exact selected-TypeScript verification-loop command; `check` validates that evidence as declared text, while CI executes the command separately.

```bash
python3 ../../scripts/project-verify.py check --root .
```

The full Git-worktree ancestry, clean-state, and changed-path gates are covered by the CLI's black-box fixtures because they require a real linked worktree.
