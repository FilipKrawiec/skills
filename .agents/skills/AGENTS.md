# Skill Editing Guardrails

Before creating or revising a skill, read `productivity/writing-great-skill/SKILL.md`.

Default to the agentskills.io model:

- write descriptions as concise activation text
- keep `SKILL.md` focused on always-needed steps or reference
- move branch-specific detail behind explicit context pointers
- avoid duplicated rules across skill body, references, and repo docs
- delete no-op instructions and generic best-practice prose

If a proposed change violates these rules, fix the structure before adding more content.
