# Entities

Reference constraints for designing Entities, derived from Vaughn Vernon's *Implementing Domain-Driven Design*.

> [!IMPORTANT]
> **Aggregate Roots are Entities:** An Aggregate Root is a specialized Entity. It inherits all rules regarding identity, equality, hash calculation, and self-validation.

## 1. Identity Constraints
- **Early vs. Late Identity:**
  - **Early Identity:** Generated before persistence (e.g., UUID/ULID). Required for event-sourced aggregates or if events containing the ID are published during creation.
  - **Late Identity:** Generated by the database (e.g., auto-increment) upon persistence. Avoid this as it complicates testing and event generation.
- **Immutability:** The identity field must be read-only and immutable. State transitions must never alter it.
- **Equality and Hash:** Entity equality (`equals()`) and hash calculations (`hashCode()`) **must be based exclusively on the unique identifier**. Other properties must be ignored. Two instances with the same identifier represent the same entity.

## 2. Invariant Validation
- **Self-Validation:** An entity must protect its own invariants and remain valid throughout its lifecycle. Never allow public setters.
- **Deconstruct Validation:**
  - **Attribute Validation:** Validate individual fields (e.g., format, range) in the constructor or setter methods.
  - **Entity Validation:** Validate invariants before state changes.
  - **Deferred Validation:** Use a separate validator strategy/object when validation requires complex rules or external resources.

## 3. Behavior and Encapsulation
- **Verbs over Nouns:** Expose state mutations only via intention-revealing domain verbs (e.g., `cancel("reason")` rather than `setStatus("CANCELLED")`).
- **Encapsulate Collections:** Never expose mutable collections. Return a read-only list/view and expose explicit methods to add/remove elements.
- **Identity References:** Never pass a collaborator Aggregate Root as an object parameter. Pass its identifier only.

```pseudocode
class Order {
  private id: OrderId          // Immutable ID
  private items: List<OrderItem> // Encapsulated collection
  private status: OrderStatus

  constructor(id, customerId) {
    if (id == null) raise Error("ID is required")
    this.id = id
    this.customerId = customerId
    this.status = OrderStatus.DRAFT
  }

  // Equality based strictly on identifier
  function equals(other): boolean {
    if (other == null || !(other is Order)) return false
    return this.id == other.id
  }

  function hash(): number {
    return hashOf(this.id)
  }

  // Encapsulated collection exposed as read-only view
  function getItems(): ReadOnlyList<OrderItem> {
    return this.items.asReadOnly()
  }

  function addProduct(productId, price, quantity) {
    if (this.status != OrderStatus.DRAFT) {
      raise Error("Cannot modify order after checkout")
    }
    
    existing = items.find(item -> item.productId == productId)
    if (existing) {
      existing.increaseQuantity(quantity)
    } else {
      items.add(new OrderItem(productId, quantity, price))
    }
  }
}
```
