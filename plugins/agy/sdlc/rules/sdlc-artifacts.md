# Antigravity SDLC Artifacts

For an SDLC-governed repository change in Antigravity, use Planning Mode. Before making workspace changes, create Antigravity's native Implementation Plan artifact with the planned scope, constraints, verification, and the current SDLC phase boundary. Do not substitute a normal chat message or a repository Markdown file for this artifact.

Request review for the Implementation Plan and wait for the user's response. With Antigravity's Artifact Review Policy set to Request Review, this creates the native Proceed button; begin the planned workspace changes only after the user uses that button or submits review feedback. If the conversation is in Fast Mode or the policy is Always Proceed, tell the user that the host will not show a Proceed button and ask them to start a Planning Mode conversation with Request Review enabled.

Keep the YAML fields and Markdown body required by the shared SDLC skill unchanged. The Implementation Plan is a host presentation and review gate only: it does not add persistence, delegation, or approval behavior to the portable SDLC contract.
