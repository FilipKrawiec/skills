# Antigravity SDLC Artifacts

When an SDLC work product is requested in Antigravity, present the completed work product through the active Antigravity conversation or artifact experience when available. Keep the YAML fields and Markdown body defined by the shared SDLC skill unchanged.

This rule adds no persistence, delegation, or approval contract beyond the portable SDLC skills. Use Antigravity-specific panels only when the active host exposes them.
