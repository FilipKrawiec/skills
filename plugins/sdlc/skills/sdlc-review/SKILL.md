# REVIEW

Validate the portable phase envelope. Check acceptance coverage, deterministic sensor evidence, skipped checks and risk, correction history, and unresolved constraints; otherwise return the contract's structured refusal. Inferential review is secondary to deterministic evidence. Return findings and request SHIP, PLAN, or EXECUTE. Only a successful review may request SHIP; do not authorize the transition.
