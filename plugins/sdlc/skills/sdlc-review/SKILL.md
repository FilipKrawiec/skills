# REVIEW

Validate the portable phase envelope. Check the plan, implementation evidence, constraints, and selected sensors; otherwise return the contract's structured refusal. Return findings and request SHIP, PLAN, or EXECUTE. Only a successful review may request SHIP; do not authorize the transition.
