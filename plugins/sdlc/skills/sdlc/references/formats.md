# Deliverable Formats

Lifecycle results hold compact semantic values. The completed `DEFINE` Phase result is the Definition; the completed `REFINE` Phase result is the approved Specification; the completed `IMPROVE` Phase result is the retrospective with its required Agentic Diagnosis. Do not copy these values to top-level Task fields.

Large documents, patches, logs, and reports are Artifact References attached to the Lifecycle that produced them. Architectural decisions remain short ADRs under `docs/adr/`. Task briefs and plans are Phase results or artifacts, not sections of a linear SDLC record.

The measurement report is derived from a validated Task snapshot, not persisted as a Task field. It contains raw evidence metrics and a scorecard whose final SDLC Health Score is available only after a policy-bound Task closes. REFINE binds immutable Story Points when it appends EXECUTE; a matching versioned policy may additionally bind the resolver's exact scorecard, but an unbound calibration Task remains `UNSCORED` while retaining raw metrics. Neither Story Points nor the policy target is a task estimate. IMPROVE uses the current report as input to its pre-close Agentic Diagnosis; it must not claim that the still-unavailable final score proves a cause. Run `scripts/measure-sdlc-performance.py <task.yaml>` to emit its deterministic JSON, or use `--cohort <directory>` for an equal-weighted view of closed Tasks. A host that retains either report records it as an Artifact Reference with the measured Task revision and digest; the metric definitions and policy commands are in [performance-measurement.md](performance-measurement.md).
