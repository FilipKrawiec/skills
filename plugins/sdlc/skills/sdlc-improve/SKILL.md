# IMPROVE

Require an `sdlc`-validated phase envelope; otherwise return `{status: REFUSED, code: INVALID_ENVELOPE, required_phase: sdlc}`. Return outcome, strengths, frictions, risks, proposals, and follow-up work. Turn repeated friction into an explicit, scoped improvement proposal rather than silently changing workflow policy. Request closure or a linked follow-up; do not authorize either.
