# IMPROVE

Validate the portable phase envelope. Return outcome, strengths, frictions, risks, proposals, and follow-up work; otherwise return the contract's structured refusal. Turn repeated friction into an explicit, scoped improvement proposal rather than silently changing workflow policy. Request closure or a linked follow-up; do not authorize either.
