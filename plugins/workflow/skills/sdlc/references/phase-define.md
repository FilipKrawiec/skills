# DEFINE Stage Phase

`sdlc-define` owns the DEFINE Stage's `DEFINE` Phase. Capture title, requested outcome, business or technical context, initial scope, and external references. Verify that the outcome is coherent and repository scope is identifiable.

The completed Phase Lifecycle result is the Definition. Record its evidence and improvement observations with that Lifecycle, then request the REFINE Stage. The Definition is not a top-level Task value and is immutable after the DEFINE Stage completes.
