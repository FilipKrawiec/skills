# REVIEW Phase

`sdlc-execute` owns this Phase inside the EXECUTE Stage. Review is independent, vigilant, and grounded in deterministic sensors. Check acceptance coverage, sensor evidence, skipped checks, correction history, and unresolved constraints.

Route planning, scope, or approach defects to an appended PLAN Phase. Route implementation-only defects to an appended EXECUTE Phase when the plan remains valid. A later REVIEW checks the correction delta and prior findings. Append SHIP only when evidence supports acceptance; do not rewrite earlier REVIEW evidence.
