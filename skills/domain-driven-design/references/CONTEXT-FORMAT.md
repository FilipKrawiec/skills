# CONTEXT.md Format

`CONTEXT.md` is a glossary, not a spec or implementation plan.

Use this shape:

```markdown
# Context

## Terms

### <Term>

Definition in domain language.

- Also called: <aliases, if any>
- Not: <near miss terms, if helpful>
```

Add only stable terms. Do not add implementation details, file paths, task notes, or unresolved guesses.
